# Расчёт отделочных материалов

Приложение для расчёта количества и стоимости отделочных материалов
(обои, плитка, ламинат) в зависимости от площади поверхности.

**Вариант 10** — Отделочные материалы.

## Описание

Программа позволяет рассчитать необходимое количество и итоговую стоимость
закупки отделочных материалов для ремонта. Поддерживаются три типа материалов:

| Материал | Единица закупки | Формула площади единицы |
|---|---|---|
| Обои     | рулон           | ширина × длина рулона |
| Плитка   | плитка          | ширина (см) × высота (см) / 10000 |
| Ламинат  | упаковка        | площадь упаковки (м²) |

Расчёт учитывает **запас на подрезку** (обычно 5–15 %), который задаётся
пользователем. Итоговый отчёт можно сохранить в формате **.docx** или **.xlsx**.

---

## Возможности

- Графический интерфейс на **Qt (PySide6)**.
- Динамическая форма параметров — поля меняются при выборе материала.
- Расчёт количества с округлением вверх и учётом запаса.
- Накопление нескольких материалов в один отчёт.
- Удаление позиций из отчёта.
- Экспорт отчёта в **.docx** (python-docx) и **.xlsx** (openpyxl).
- Валидация всех входных данных (managed-атрибуты через `@property`).
- Покрытие тестами через **pytest**.

## Использование

### Пошагово

1. **Выберите материал** в выпадающем списке: Обои / Плитка / Ламинат.
2. **Заполните параметры** — поля формы автоматически меняются под
   выбранный материал:
   - для обоев: ширина рулона, длина рулона, цена за рулон;
   - для плитки: ширина и высота плитки (в см), цена за плитку;
   - для ламината: площадь упаковки (м²), цена за упаковку.
3. **Укажите площадь** поверхности в м² и **запас на подрезку** в процентах.
4. Нажмите **«Рассчитать»** — появится окно с количеством и стоимостью.
5. Нажмите **«Добавить в отчёт»** — позиция появится в таблице внизу.
6. Повторите шаги 1–5 для остальных материалов.
7. Нажмите **«Сохранить .docx»** или **«Сохранить .xlsx»** — выберите
   папку и имя файла в диалоге сохранения.

### Пример расчёта

Помещение 20 м², запас 10 %:

| Материал | Количество | Стоимость |
|---|---|---|
| Обои (1.06 × 10 м, 1500 ₽/рулон) | 3 рулона | 4 500 ₽ |
| Плитка (30 × 30 см, 120 ₽/шт)    | 245 шт   | 29 400 ₽ |
| Ламинат (2.13 м²/уп, 900 ₽/уп)   | 11 уп    | 9 900 ₽ |
| **ИТОГО**                         |          | **43 800 ₽** |

### Краткая справка по формулам

- **Количество** = ⌈площадь × (1 + запас) / площадь единицы⌉
- **Стоимость** = количество × цена за единицу

Округление всегда **вверх** — нельзя купить дробное число рулонов.

## Тесты

Запуск всех тестов:

```bash
pytest -v
```

Запуск конкретного класса или метода:

```bash
pytest tests/test_materials.py::TestWallpaper -v
pytest -k "wallpaper" -v
```

Тесты покрывают:
- валидацию managed-атрибутов (негативные значения, `bool`, нечисловые типы);
- корректность формул для обоев, плитки, ламината;
- граничные случаи (`ceil` при целочисленных значениях, float-погрешность);
- dunder-методы (`__str__`, `__repr__`, `__lt__`, `__hash__`);
- агрегацию нескольких материалов в `Summary`;
- создание файлов отчётов `.docx` и `.xlsx`.

## Архитектура

Проект разделён на три слоя:

### 1. Модели — `lab2/materials.py`

Абстрактный базовый класс `Material` и три наследника: `Wallpaper`, `Tile`,
`Laminate`. Каждый класс хранит **данные** материала и умеет считать
**площадь одной единицы** (`unit_area`) и её название (`unit_name`).

- используется `abc.ABC` + `@abstractmethod`;
- managed-атрибуты через `@property` и сеттеры с валидацией;
- dunder-методы `__str__`, `__repr__`, `__eq__`, `__lt__`, `__hash__ = None`.

### 2. Расчёты — `lab2/calculator.py`

Универсальный `MaterialCalculator` не знает про конкретные материалы и
работает с любым объектом `Material` по одной формуле. Результат каждого
расчёта — `CalculationResult`, агрегация нескольких — `Summary`.

- `CalculationResult` и `Summary` — `@dataclass`;
- валидация входных параметров (площадь, запас) в одном месте;
- защита от float-погрешности при `math.ceil`.

### 3. Экспорт — `lab2/report.py`

Абстрактный `BaseReportWriter` и два наследника: `DocxReportWriter`,
`XlsxReportWriter`. Общая логика (создание папки, имя файла, проверка типа)
в базовом классе, специфика формата — в наследниках.

- `@abstractmethod _write_report`;
- удобная обёртка `save_all()` для сохранения сразу в оба формата.

### Интерфейс — `main.py`

Графический интерфейс на **PySide6** (`QMainWindow` + виджеты). Полностью
разделён с бизнес-логикой: интерфейс только вызывает методы пакета `lab2`.
